Binnen dit project is Proxmox VE ingericht als virtualisatieplatform ter ondersteuning van mijn Infrastructure as Code (IaC) leertraject.
Het doel van deze setup is het creëren van een realistische, schaalbare en beheersbare infrastructuur, vergelijkbaar met die van een organisatieomgeving, maar dan uitgevoerd binnen een homelab.

Proxmox fungeert hierbij als centrale hypervisorlaag, waarop virtuele machines uitgerold kunnen worden via IaC-principes.
